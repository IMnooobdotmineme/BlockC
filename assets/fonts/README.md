# PDF fonts

Noto Sans and Noto Sans Thai are embedded locally in certificate PDFs.

Sources:
- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/google/fonts/tree/main/ofl/notosansthai

Downloaded from the official Noto/Google font repositories for Step 6. Noto Sans
uses the static Regular font to avoid variable-font subset rendering problems.
Files retain their original
SIL Open Font License notices in `NotoSans-OFL.txt` and `NotoSansThai-OFL.txt`.
These files are included in the PDF route's production file trace.
